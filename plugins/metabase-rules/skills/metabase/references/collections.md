# Metabase collections — recommendations

Recommendations for placing entities in Metabase collections. Prefer these
defaults; deviate when a situation genuinely warrants it.

1. Unless a target collection is explicitly specified, create new entities —
   questions, dashboards, models, collections — in the acting user's
   personal collection. Shared collections are curated surfaces that should
   not accumulate drafts and experiments; the personal collection is the
   safe sandbox, and moving an entity to a shared home later is cheap.
   Every user has a personal collection on every Metabase instance, so this
   default needs no per-instance configuration.
